## 📌 Descripción

Sitio web tipo portafolio desarrollado con tecnologías web básicas para presentar mi trabajo como desarrollador.

Incluye:

* Presentación personal
* Sección de habilidades
* Proyectos destacados
* Diseño responsivo

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## 📂 Estructura del proyecto

```
outputs/
│
├── index.html
├── styles.css
├── script.js
└── assets/
```

## 🚀 Cómo ejecutarlo localmente

1. Clonar el repositorio:

```bash
git clone https://github.com/Damahibe/Portfolio.git
```

2. Abrir la carpeta:

```bash
cd Portfolio
```

3. Abrir `index.html` en el navegador
